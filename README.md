# Pilo Étudiant

**Pilo Étudiant** est une application web conçue pour aider les étudiants à gérer leur budget et à suivre leurs dépenses.

## Fonctionnalités

* Création de compte et connexion.
* Suivi des dépenses.
* Gestion du budget étudiant.
* Enregistrement des transactions.
* Tableau de bord pour consulter les informations financières.

## Technologies utilisées

* Python
* Flask
* SQLite
* HTML et CSS
* Gunicorn

## Installation locale

1. Clonez le dépôt :

   ```bash
   git clone https://github.com/fio-doct/AGRODATA-BENIN.git
   ```

2. Entrez dans le dossier :

   ```bash
   cd AGRODATA-BENIN
   ```

3. Installez les dépendances :

   ```bash
   pip install -r requirements.txt
   ```

4. Lancez l'application :

   ```bash
   python app.py
   ```

## Déploiement

L'application est destinée à être déployée sur Render.
